# Portfólio Reflexivo · Gael Aleixo

Portfólio reflexivo do curso de **Tecnologia em Sistemas para Internet** (IFSP Campus Birigui), 1º e 2º semestres de 2026.

Site estático em HTML, CSS e um pouco de JavaScript, sem dependências de build. Identidade visual em petróleo, dourado e prata.

## Estrutura

```
index.html      página única, com todas as seções
css/style.css   estilos e paleta
js/main.js      menu móvel, destaque da seção atual e animação de entrada
```

## Ver localmente

Abra o `index.html` no navegador, ou sirva a pasta:

```bash
python -m http.server 8765
```

e acesse http://127.0.0.1:8765.
